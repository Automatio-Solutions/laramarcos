# Brand: LaraMarcos Asesores

> Gestoría / asesoría — Estética: Financial Pro (navy sobrio, profesional, fiable)

## Paleta

| Rol | Hex | Uso |
|-----|-----|-----|
| Primary | #1F223E | CTAs, links, focus rings, active states, header/sidebar |
| Secondary | #828999 | Botones secundarios, tags, badges, texto de apoyo |
| Accent | #5B6699 | Highlights, notificaciones, indicadores de progreso |
| Neutral | #6E7585 | Bordes, divisores, estados disabled |
| Surface | #FFFFFF | Fondo base (terciario de marca: blanco) |

## Tipografía

- **Heading**: Plus Jakarta Sans (bold/semibold)
- **Body**: Plus Jakarta Sans (regular, 16px base)
- **Label**: Plus Jakarta Sans (medium, 14px)
- **Mono**: JetBrains Mono (bloques de código / importes monoespaciados)

## Forma

- **Radius**: Medium (8px base) — botones 8px, cards 12px, inputs 8px
- **Shadows**: sutiles — shadow-sm por defecto, shadow-md para cards elevadas
- **Borders**: 1px solid neutral-200 (light) / neutral-700 (dark)

## Reglas

1. Primary (navy) solo para CTAs principales y elementos interactivos primarios.
2. Secondary (grey) para acciones secundarias, nunca para texto de cuerpo.
3. Fondo blanco; neutral-50 para cards, neutral-100 para fondos de sección.
4. Contraste mínimo 4.5:1 (AA) para texto.
5. Dark mode usa las variantes claras del navy (#8B93C4) sobre fondo #14162A.
6. Estética sobria de despacho: sin gradientes, sin saturación; transmite confianza y orden.
7. Datos numéricos/importes/CIF alineados y legibles (tablas densas pero claras).
